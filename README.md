# Contributions du CCJ Lambaye

Page React permettant de contribuer directement à Lambaye avec le QR code ou le lien Wave.

## Lancer le site

Installer les dépendances avec `npm install`, puis lancer `npm run dev`.

La page n'enregistre pas et ne vérifie pas automatiquement les paiements. Après le paiement, elle remercie simplement le contributeur pour son soutien à un Lambaye plus propre et plus vert.
