# Contributions du CCJ Lambaye

Page React permettant d'effectuer une contribution avec le QR code ou le lien de paiement Wave, puis d'envoyer un rapport privé au CCJ par WhatsApp.

## Lancer le site

Installer les dépendances avec `npm install`, puis lancer `npm run dev`.

La page n'enregistre et ne vérifie pas automatiquement les paiements. Le contributeur effectue son paiement dans Wave, confirme ensuite le paiement sur le formulaire, puis envoie son rapport par WhatsApp.
